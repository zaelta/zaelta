### 🌐 Profile Overview

```yaml
role: Automation & Software Engineer
focus: Industrial Control Systems (OT) & High-Performance Software (IT)
ecosystem: CODESYS, Multi-Axis CNC / Motion, Full-Spectrum .NET
platforms: Windows Embedded / Desktop, Industrial PLCs, Real-Time Fieldbuses
mindset: Deterministic Reliability, Modular Architecture, Sub-millisecond Execution
```

I architect and deliver robust, end-to-end industrial software solutions spanning from low-level deterministic field control to modern high-performance desktop architectures:

* 🏭 **Industrial Automation & Motion Systems:** Deep domain expertise in **CODESYS (IEC 61131-3)**, structured PLC logic, multi-axis motion synchronization, kinematics, and comprehensive on-site commissioning of CNC machinery.
* 💻 **Full-Spectrum .NET Engineering:** Comprehensive proficiency across legacy and next-gen platforms — maintaining rock-solid **.NET Framework 4.8 / Windows Forms** foundations while engineering modern solutions on **.NET 8, 9 & 10**, **WPF**, and cross-platform **.NET MAUI**.
* 🔌 **Hardware & Industrial Communications:** Direct hardware interfacing, high-frequency data acquisition pipelines, and protocol implementations (**Modbus TCP/RTU**, **OPC UA**, **CANopen**, **EtherCAT**, **RS-485**, **TCP/UDP Sockets**).
